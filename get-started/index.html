Try signet

Signet is a Bitcoin test network. This two-minute run checks that the node starts, connects to peers, and begins syncing.

--milestone 0 enables all historical script checks. Wallet interfaces stay off for this first run.

Keep syncing

Look for ibd: progress messages in the terminal as syncing gets underway. The process stops after two minutes; that does not mean syncing is complete. If there is no progress, check the operator guide.

To continue, run the same command without --max-run-secs 120. Press Ctrl+C to stop. Restart with the same --datadir to resume.

Before mainnet

Plan for a 1 TB-class disk, with room for growth. This release keeps a full archive; wallet indexes need extra space while building. Storage requirements.

rbitcoin is an independent consensus implementation and is still pre-1.0. A short signet run is only a first check. Before relying on mainnet, compare with another node and monitor reorgs and free disk space. Use a separate mainnet data directory and follow the mainnet runbook.

In v0.7.0, the mainnet default skips script and signature checks at or below block 840,000. Other checks still run. Set --milestone 0 to check every historical script. About validation defaults.
